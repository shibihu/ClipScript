โปรเจกต์ของฉัน

เทมเพลตเริ่มต้น

เลือกโครงสร้างเพื่อเริ่มทำคลิปได้เร็วขึ้น

คู่มือการใช้งาน

เริ่มทำโปรเจกต์แรกในไม่กี่ขั้นตอน

1. สร้างโปรเจกต์

กด “สร้างโปรเจกต์ใหม่” ตั้งชื่อคลิป แล้วเลือกเป้าหมายของวิดีโอ

2. แบ่งสคริปต์เป็นฉาก

แนะนำให้แต่ละฉากมีใจความเดียว เพิ่มเสียงพากย์ ภาพที่ต้องการค้นหา ข้อความบนจอ และเสียงเอฟเฟกต์

3. กำหนดเวลา

ใส่เวลาเริ่มและเวลาจบของแต่ละฉากตามเสียงพากย์จริง ระบบจะใช้ข้อมูลนี้สร้างไฟล์ Subtitle SRT หรือกดปุ่ม “Auto Timeline” ในหน้าแก้ไขเพื่อให้ระบบประมาณเวลาจากบทพูดก่อน (เป็นค่าประมาณเท่านั้น)

4. ส่งออก

ส่งออก Markdown สำหรับแผนงาน, CSV สำหรับตารางฉาก, SRT สำหรับ Subtitle หรือ JSON เพื่อสำรองและย้ายโปรเจกต์

ข้อมูลเวอร์ชันนี้เก็บในเบราว์เซอร์ของอุปกรณ์คุณ หากล้างข้อมูลเว็บไซต์ โปรเจกต์อาจหายได้ ควรส่งออก JSON เพื่อสำรองเป็นระยะ
