# ClipScript TH — MVP ต้นแบบ

## วิธีเปิดใช้งาน
1. ดาวน์โหลดและแตกไฟล์ ZIP
2. เปิด `index.html` ในเบราว์เซอร์สมัยใหม่
3. กด “สร้างโปรเจกต์ใหม่” เพื่อเริ่มใช้งาน

ไม่ต้องติดตั้ง Node.js, ไม่ต้องมี API Key และไม่ต้องมี Backend สำหรับต้นแบบนี้

## ความสามารถในเวอร์ชันนี้
- Dashboard ภาษาไทยแบบ Responsive
- สร้างโปรเจกต์จากเทมเพลต H.C.B.R, Everyday Curiosity และ Product Showcase
- เพิ่ม/แก้ไข/ลบ/จัดเรียงฉาก
- บันทึกใน LocalStorage ของเบราว์เซอร์
- ส่งออก Markdown, CSV, SRT และ JSON
- นำเข้าไฟล์สำรอง JSON
- Auto Timeline: ประมาณเวลาพากย์ของแต่ละฉากจากบทพูด (ไทย/อังกฤษ/ผสม) แสดงตัวอย่างก่อนใช้ ปรับเวลาเองได้ และเลือกความยาวเป้าหมายเพื่อวางแผน (15/30/45/60/90 วินาที)
- Export Markdown เพิ่มบรรทัด “ระยะเวลา” และ CSV เพิ่มคอลัมน์ท้ายสุด “Duration (s)” (SRT ไม่เปลี่ยน)

## Auto Timeline
- ไฟล์ที่ต้องอยู่คู่กัน: `index.html` และ `autotimeline.js` (ถ้า deploy ต้องอัปโหลดทั้งสองไฟล์ ถ้าไม่มี `autotimeline.js` ฟีเจอร์เดิมยังใช้ได้ แต่ปุ่ม Auto Timeline จะไม่แสดง)
- วิธีประมาณ: นับตัวอักษร/ตัวเลขที่ออกเสียงด้วย grapheme (Intl.Segmenter ถ้ามี) ÷ ความเร็วอ่าน (ช้า 8 / ปกติ 11 / เร็ว 14 ตัวอักษรต่อวินาที หรือกำหนดเอง) + หยุดท้ายประโยค 0.4 วินาที + หยุดระหว่างย่อหน้า 0.6 วินาที (ขั้นต่ำ 1 วินาทีต่อฉากที่มีบทพูด)
- เป็น **ค่าประมาณ** ไม่ได้วิเคราะห์ไฟล์เสียงจริง และ SRT ไม่ได้ซิงก์กับเสียงจริง
- ใช้ฟิลด์ `start`/`end` เดิมของฉาก ไม่มีฟิลด์เวลาใหม่ในฉาก (โปรเจกต์อาจมีฟิลด์เสริม `timelineSettings` เก็บความเร็วอ่าน; JSON เก่าที่ไม่มีฟิลด์นี้ใช้ได้ตามปกติ)

## ทดสอบ
- ตรรกะคำนวณ: `node --test tests/` (ต้องใช้ Node 18+ ไม่ต้องติดตั้งแพ็กเกจ)
- ทดสอบด้วยมือในเบราว์เซอร์: สร้างโปรเจกต์ → ใส่บทพูด → กด Auto Timeline → คำนวณ → ดูตัวอย่าง → ยกเลิก (เวลาต้องไม่เปลี่ยน) → คำนวณอีกครั้ง → ใช้ → แก้ เริ่ม/จบ เอง → ปิดและเปิดใหม่/รีเฟรชหน้า → นำเข้า JSON เก่า → Export ทุกรูปแบบ → ลองหน้าจอมือถือ (กว้าง ≤ 700px) และกรอกค่าผิด (ว่าง, ติดลบ, ตัวอักษร)

## ข้อจำกัด
- ข้อมูลอยู่ในเบราว์เซอร์เครื่องนี้ ไม่ได้ซิงก์ข้ามอุปกรณ์
- ไม่มี AI API ในเวอร์ชันนี้
- ควร Export JSON สำรองไว้เป็นระยะ
- SRT ใช้เวลาเริ่ม/จบที่ผู้ใช้กำหนด และใช้ข้อความบนจอเป็นหลัก (หากว่างจะใช้เสียงพากย์)

## เผยแพร่ฟรี
สามารถนำไฟล์ `index.html` ไป deploy เป็น static site บน Cloudflare Pages หรือ GitHub Pages ได้ โดยไม่ต้องใส่ API Key
